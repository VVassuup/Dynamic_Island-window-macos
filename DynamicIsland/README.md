# Dynamic Island для Windows

Остров в стиле iPhone сверху экрана: музыка, тексты песен, уведомления Windows и Telegram.

## Возможности
- Компактная «таблетка» → при наведении плавно раскрывается в мини-плеер (пружинящая анимация).
- Текущий трек из любого источника: Spotify, Яндекс Музыка, **YouTube в браузере** (Chrome/Edge/Firefox/Opera), VLC, AIMP, Telegram…
- Обложка в виде **вращающейся пластинки** (останавливается на паузе), анимированный эквалайзер.
- Перемотка (ползунок), предыдущий / пауза / следующий, время и остаток.
- **Недавние треки** (последние 5), клик — поиск трека на YouTube.
- **Синхронный текст песни** (текущая + следующая строка) с lrclib.net.
- Уведомления Windows и Telegram прямо в острове, очередь, скрытие по клику.
- Настройки: размер, отступ, вкл/выкл уведомлений Windows и Telegram отдельно, длительность показа.
- Бонусы: цвет акцентов подстраивается под обложку, часы когда ничего не играет, режим «Не беспокоить»,
  автоскрытие в полноэкранных играх, автозапуск с Windows, иконка в трее, не крадёт фокус и пропускает клики вокруг себя.

## Сборка
Требуется Windows 10 (2004+) или Windows 11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bat
cd DynamicIsland
dotnet run
```

Готовый exe:
```bat
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
Файл появится в `bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\DynamicIsland.exe`.
(Или просто запусти `build.bat`.)

Можно также открыть `DynamicIsland.csproj` в Visual Studio 2022 и нажать F5.

## Настройка уведомлений
1. **Windows**: Параметры → Конфиденциальность и защита → Уведомления → включить «Доступ к уведомлениям» для приложений.
2. **Telegram Desktop**: Настройки → Уведомления и звуки → включить «Использовать системные уведомления».
   Остров читает уведомления из Центра уведомлений Windows и распознаёт Telegram по имени приложения.
3. Чтобы стандартные баннеры в углу не дублировались: Параметры → Система → Уведомления → нужное приложение →
   выключить «Показывать баннеры», но оставить «Показывать в центре уведомлений».

> Важно: на некоторых сборках Windows API чтения уведомлений (`UserNotificationListener`) работает только у приложений
> с «идентификатором пакета» (MSIX). Если остров пишет «Нет доступа к уведомлениям», хотя доступ включён, —
> упакуй проект в MSIX (Visual Studio → Windows Application Packaging Project) и добавь в манифест capability
> `<uap3:Capability Name="userNotificationListener" />`. Музыка и всё остальное работает без этого.

## Управление
- **Клики сквозь остров** (включено по умолчанию): остров не мешает нажимать на то, что под ним.
  Чтобы управлять островом — зажми **Ctrl** (можно сменить на Alt/Shift в настройках) и наведи курсор.
  Раскрытый остров остаётся кликабельным, пока курсор на нём. Включить/выключить — в настройках или в трее.
- Навести на остров — раскрыть мини-плеер; увести курсор — свернуть.
- Клик по уведомлению — закрыть его.
- Иконка в трее: настройки, «Не беспокоить», показать/скрыть, тестовое уведомление, выход.

Настройки хранятся в `%AppData%\DynamicIsland\settings.json`.

## Установщик (v3.0)

1. Установи [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и [Inno Setup 6](https://jrsoftware.org/isdl.php) (или `winget install JRSoftware.InnoSetup`).
2. Запусти `build_installer.bat`.
3. Готовый установщик: `dist\DynamicIsland_Setup_3.0.0.exe`.

Установщик спрашивает язык (русский / English), ставит программу без прав администратора, создаёт ярлык в «Пуске» (по желанию — на рабочем столе), может включить автозапуск и корректно удаляется через «Установленные приложения». Язык, выбранный в установщике, сразу применяется в программе.

## Язык

Настройки → **ЯЗЫК / LANGUAGE** или трей → «Язык / Language». Переключается на лету. Добавить язык — дописать столбец в `Loc.cs`.

## Клики сквозь остров

При включённой настройке клики проходят к окнам под островом **везде, кроме кнопок острова** (play/pause, перемотка, вкладки, ползунок, список недавних треков, уведомления). Никаких клавиш зажимать не нужно — остров раскрывается при наведении, как раньше.

## Иконки

`Assets/app.ico` — иконка программы и окна настроек, `Assets/tray-light.ico` / `tray-dark.ico` — трей (подбирается под светлую/тёмную панель задач автоматически), `installer/installer.ico` — иконка установщика.

## v4.0 — интерфейс как на Mac + громкость

- Внешний вид, шрифт и расположение кнопок повторяют macOS-версию.
- Справа от названия трека — ползунок громкости: перетаскивание вверх/вниз, клик — mute, колёсико — точная подстройка. Выключается в настройках («Ползунок громкости»).
- Шрифт SF Pro лицензия Apple не разрешает вкладывать в программу. Если он установлен в Windows, остров использует его, иначе — Segoe UI Variable.
